Entry for the [make.fun bounty "Famous Last Words: The Funniest Epitaph"](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406).

`main.py` (stdlib-only Python) writes a single-line tombstone epitaph of
famous last words to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set) — one line, 52 characters, inside the 150-character limit:

> Tell the kids I loved them. Tell the bank I did not.
